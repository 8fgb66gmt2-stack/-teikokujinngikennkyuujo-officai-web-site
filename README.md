# 帝國神祇研究所 公式情報網

**IMPERIAL INSTITUTE OF SHINTO STUDIES**

日ノ本帝國の架空国家機關「帝國神祇研究所」の公式サイトです。

## ファイル構成

- `index.html` — トップページと各案内
- `style.css` — レスポンシブデザイン
- `script.js` — 史料目録検索、分類フィルター、閲覧案内ダイアログ

## GitHub Pages の公開設定

1. リポジトリの **Settings** を開く
2. 左メニューの **Pages** を選択
3. **Build and deployment** の **Source** を **Deploy from a branch** に設定
4. Branch を **main**、フォルダーを **/(root)** にして **Save**

公開後のURLは通常、次の形式です。

https://8fgb66gmt2-stack.github.io/-teikokujinngikennkyuujo-officai-web-site/

## メモ

- 公開目録の項目と閲覧制限に關する記述は創作設定です。
- 「宮内廳」「帝國内閣官報枢府」「帝國大學」のリンク先は、接続先を設定するまで案内ダイアログを表示します。
- 史料検索欄に `SH-000` と入力すると、非公開史料に關する隠し案内が表示されます。
